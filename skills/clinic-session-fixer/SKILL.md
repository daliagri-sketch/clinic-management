## הקשר — מה האפליקציה

אפליקציית Next.js לניהול קליניקה טיפולית של דליה גרינבאום.
URL פרודקשן: https://clinic-management-53sf.vercel.app

**דפים:**
- `/` — רשימת מטופלים (עריכה, iCount ID, תעריף)
- `/matching?month=YYYY-MM` — התאמה חודשית יומן ↔ מטופלים
- `/patients/[id]?month=YYYY-MM` — פגישות חודשיות של מטופל בודד
- `/summary?month=YYYY-MM` — סיכום חודשי: כל המטופלים + תשלומים

**מקורות נתונים:**
- Supabase: טבלות `patients`, `sessions`, `ignored_events`
- Google Calendar: חשבון daliagri@gmail.com
- iCount: מערכת חשבוניות, CID=daliagri

## כשמתבקשים לתקן חודש — סדר הפעולות

### שלב 1 — ברר מה צריך תיקון

שאל: איזה חודש? האם יש שמות ספציפיים לתקן? האם יש iCount IDs חסרים?

אם לא צוין — פתח `/matching` של החודש הנוכחי וסרוק את הרשימה.

### שלב 2 — תיקון זיהויים שגויים

לכל שורה שמוצגת עם שם שגוי (הותאמה אוטומטית לא נכון):
1. לחץ על **"שנה"** באותה שורה
2. בחר מהרשימה הנכונה — או לחץ **"+ מטופל חדש"** אם המטופל לא קיים
3. אם לוחצים על "מטופל חדש": מלא שם + מזהה iCount אם ידוע → לחץ "צור מטופל"
4. לאחר הבחירה: לחץ "שמור לסשן"

### שלב 3 — עדכון סטטוס פגישות

לכל פגישה שנשמרה:
- שנה **סטטוס פגישה** → "התקיימה" אם ידוע שהתקיימה
- שנה **שולם** → "שולם" + בחר אופן תשלום (מזומן/ביט/העברה/פייבוקס)

### שלב 4 — הפקת חשבוניות

תנאים להפקה (הכפתור מופיע רק כשכולם מתקיימים):
- סטטוס = "התקיימה"
- שולם = "שולם"
- למטופל יש מזהה iCount
- לא הופקה חשבונית עדיין

לחץ **"הנפק"** — החשבונית נוצרת ישירות ב-iCount.

### שלב 5 — עדכון iCount ID חסר

אם למטופל אין מזהה iCount:
1. עבור לדף `/` (רשימת מטופלים)
2. לחץ על שם המטופל
3. מלא **מזהה iCount** בתיבה הרלוונטית
4. לחץ "שמירה"
5. חזור ל-matching והפק חשבונית

## תיקון מהיר דרך SQL (Supabase Dashboard)

כאשר יש תיקונים רבים לאותו חודש, יעיל יותר להריץ SQL ב-Supabase Dashboard → SQL Editor:

```sql
-- עדכון iCount ID לפי שם
update patients set icount_id = '1692' where name ilike '%בר%' and name ilike '%וסול%';

-- מחיקת session שגוי לפי event_id
delete from sessions where event_id = 'EVENT_ID_HERE';

-- תיקון alias שגוי
update patients set calendar_aliases = array['שם מדויק'] where name ilike '%שם%';
```

## כללי ברזל

- לא מוחקים sessions ללא אישור מפורש של דליה
- לא מנפיקים חשבוניות ללא אישור שהתשלום התקבל
- לא משנים iCount ID של מטופל שכבר יש לו חשבוניות — לבדוק קודם ב-iCount
- כל שינוי במזהה iCount — לדווח לדליה לפני ביצוע
